Verse Parse — Privacy Policy

Last updated: 2026-05-27

English 中文

Overview

Verse Parse is a Chrome extension that helps Chinese-speaking users read Japanese text. Analysis runs locally by default. You may optionally enable AI (Gemini, Groq, or OpenRouter) in options using your own API keys.

Data we process

When you trigger analysis (select text, context menu, Ctrl+Shift+Y, or toolbar action), the extension reads:

  • Selected text (may include ruby markup for readings)
  • Current page URL (stored locally in analysis metadata; not sent to our servers)

The extension does not scrape full pages or scan content in the background.

Optional AI

If you enable AI and provide an API key, selected text is sent over HTTPS to the provider you choose. Keys are stored only in chrome.storage.local on your device. We do not collect or relay your keys.

概述

Verse Parse 是面向中文用户的日语阅读辅助 Chrome 扩展。默认本地分析；可在选项页自愿启用 AI（Gemini / Groq / OpenRouter）并自行提供 API Key。

处理的数据

仅在您主动操作（划选、右键菜单、快捷键 Ctrl+Shift+Y、工具栏）时读取：

  • 选中的文本（可能含 ruby 注音）
  • 当前页面 URL（仅存于本地分析元数据）

不会主动抓取整页或后台扫描。

可选 AI

启用 AI 并填写 Key 后，选中文字经 HTTPS 发送至您选择的第三方。Key 仅保存在本机 chrome.storage.local。
